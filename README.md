# Prabidhi Uthaan

A multi-page Next.js website for an incubation and venture-building company.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload this folder or push it with Git.
3. Import the repository at https://vercel.com/new.
4. Keep the default Next.js settings.
5. Click Deploy.

## Before launch
- Connect the application form to an email service, database, or CRM.
- Replace placeholder metadata and add your official domain.
- Add legal pages: privacy, terms, investment-risk disclosure, and an equity-partnership agreement workflow.
- Have a qualified legal/accounting professional review the investment structure and securities compliance in Nepal.
